## 5. REQUISITOS TÉCNICOS

```
FRONT-END
  • Stack sugerido: React + Tailwind CSS (o Next.js si requiere SEO/SSR)
  • Totalmente responsive (mobile-first): breakpoints 375 / 768 / 1024 / 1440
  • Animaciones sutiles con Framer Motion (fade-in on scroll, hover 3D
    suave en tarjetas de producto)
  • Optimización de imágenes (lazy loading, formato WebP)
  • Accesibilidad: contraste AA, navegación por teclado, alt text en
    todas las imágenes de producto

E-COMMERCE
  • Catálogo con filtros (tipo de joya, material, rango de precio,
    disponibilidad de esmeralda)
  • Ficha de producto: galería zoom, selector de talla/material,
    certificado de autenticidad descargable, botón WhatsApp de asesoría
  • Carrito lateral + checkout simplificado (integración pasarela de
    pago: Wompi / PayU / Mercado Pago para Colombia)
  • Sección "Club Ángel" (newsletter con beneficios VIP)

SEO / PERFORMANCE
  • Meta tags optimizados para "joyas de esmeraldas Colombia",
    "esmeraldas certificadas", "joyería de lujo Medellín/Colombia"
  • Schema.org tipo Product + Organization
  • Core Web Vitals en verde (LCP < 2.5s, CLS < 0.1)
```
