## 0. CÓMO USAR ESTE DOCUMENTO

Este archivo es un **prompt maestro** listo para copiar y pegar en cualquier
herramienta de generación de código/diseño con IA (v0, Claude, Cursor,
Lovable, Bolt, Framer AI, etc.) para construir el sitio web completo de
**Ángel Joyas & Esmeraldas**, tomando como referencia visual y estructural
la maquetación de "Aurelia Jewelry" y la identidad de marca del logo
dorado sobre fondo verde esmeralda.

**Dos formas de usarlo:**

- **Modo completo:** copia desde `## 1. CONTEXTO Y ROL` hasta
  `## 15. INSTRUCCIÓN FINAL` y pégalo como una sola instrucción. Mejor
  para herramientas con ventanas de contexto grandes (Claude, Cursor).
- **Modo modular:** si la herramienta genera mejor por partes (v0,
  Lovable), usa los bloques listos de la sección `## 12. PROMPTS
  MODULARES`, uno por sección del sitio, en orden.

```
Actúa como diseñador UI/UX senior y desarrollador Front-End experto en
e-commerce de lujo (nivel Cartier, Tiffany & Co., Aurelia Jewelry). Vas a

## 2. IDENTIDAD DE MARCA

### 2.1 Paleta de colores

```
┌────────────────────────────────────────────────────────────────┐
│  TOKEN               HEX         USO                            │
├────────────────────────────────────────────────────────────────┤
│  --color-emerald-900 #0B3D2E     Fondo principal / hero         │
│  --color-emerald-700 #14523E     Secciones alternas             │
│  --color-emerald-950 #08281D     Sombras / degradado profundo   │
│  --color-gold-500    #C9A66B     Acentos, botones, líneas        │
│  --color-gold-300    #E8C989     Hover, detalles, íconos         │
│  --color-cream-100   #F5EFE4     Fondos claros / producto        │
│  --color-ink-900     #12100E     Tipografía / footer             │
│  --color-white       #FFFFFF     Texto sobre fondo oscuro        │
└────────────────────────────────────────────────────────────────┘

Gradiente de marca (hero / fondos oscuros):
   radial-gradient(circle at top right,
        #1A5C43 0%, #0B3D2E 45%, #08281D 100%)

Reglas de contraste:
  · Texto dorado (#C9A66B) sobre verde oscuro (#0B3D2E) → AA para texto
    grande (≥18px o 14px bold). Para texto de cuerpo pequeño, usar
    #E8C989 o blanco para cumplir AA en texto normal.
  · Nunca combinar dorado sobre crema sin aumentar peso/tamaño: el
    contraste es bajo. Usar --color-ink-900 para cuerpo de texto sobre
    fondo crema.
```

### 2.2 Sistema tipográfico

```
Encabezados (H1-H3):   "Cormorant Garamond" o "Playfair Display"
                        letter-spacing: 0.08em–0.15em según tamaño
                        H1 hero en mayúsculas, ej. "Á N G E L"

Subtítulos / cuerpo:    "Montserrat Light" o "Jost"
                        letter-spacing: +0.02em, minúsculas

Botones / navegación:   "Montserrat" 500, mayúsculas, tracking +0.1em

Escala tipográfica (base 16px, ratio 1.25):
  H1: 56px / 64px (desktop) — 36px / 42px (mobile)
  H2: 40px / 48px           — 28px / 34px
  H3: 28px / 36px           — 22px / 28px
  Body: 16px / 26px
  Small: 13px / 20px
```

### 2.3 Sistema de espaciado y grid

```
Escala de espaciado (múltiplos de 4px): 4·8·12·16·24·32·48·64·96·128

Grid desktop:   12 columnas, margen lateral 80px, gutter 24px
Grid tablet:    8 columnas,  margen lateral 40px, gutter 20px
Grid mobile:    4 columnas,  margen lateral 20px, gutter 16px

Breakpoints:    375px · 768px · 1024px · 1440px
Contenedor máx: 1440px, centrado
```

### 2.4 Logotipo y elementos gráficos

```
- Monograma "A" estilizado en trazo dorado degradado, usado como
  favicon, watermark y loader (animación de trazo dibujándose, 1.2s).
- Ícono de alas + corazón pequeño como sello de marca (footer,
  certificados de autenticidad, empaques, confirmaciones de compra).
- Líneas finas doradas como separadores de sección (1px, opacidad 60%).
- Texturas: fondo con textura de piedra pulida / mármol sutil, muy baja
  opacidad (≤8%), solo en secciones "Nuestra Historia" y footer.
- El logo NUNCA se deforma, rota ni se coloca sobre fondos de bajo
  contraste (evitar sobre crema claro sin contenedor oscuro).
```

### 2.5 Componentes UI

```
BOTÓN PRIMARIO
  Reposo:  fondo #C9A66B, texto #12100E, radio 2px, padding 14px 32px
  Hover:   fondo #E8C989, leve elevación (shadow dorado suave)
  Focus:   outline 2px #E8C989 offset 2px (accesibilidad teclado)

BOTÓN SECUNDARIO (outline)
  Reposo:  borde 1px #C9A66B, texto #C9A66B, fondo transparente
  Hover:   fondo #C9A66B 10% opacidad

TARJETA DE PRODUCTO
  Radio 4px, sombra sutil en hover, zoom de imagen 1.05 (400ms ease-out)
  Precio siempre visible, sin ocultar tras hover

INPUT / FORMULARIO
  Línea inferior dorada, sin bordes completos, label flotante,
  estado de error en tono coral discreto (no rojo puro, para mantener
  la paleta de lujo)
```

## 6. PÁGINAS INTERNAS

```
CATÁLOGO (/coleccion)
  - Filtros: tipo de joya, material, rango de precio, disponibilidad de
    esmeralda, tamaño.
  - Orden: relevancia, precio (asc/desc), novedades.
  - Grid 4 columnas desktop → 2 tablet → 1 mobile.
  - Estado vacío ("sin resultados") con sugerencia de limpiar filtros.

FICHA DE PRODUCTO (/producto/[slug])
  - Galería con zoom (hover desktop, pinch mobile), miniaturas laterales.
  - Selector de talla/material con disponibilidad en tiempo real.
  - Certificado de autenticidad descargable en PDF.
  - Botón "Consultar por WhatsApp" con mensaje precargado.
  - Sección "También te puede interesar" (3-4 productos relacionados).
  - Breadcrumb: Inicio / Colección / Categoría / Producto.

NUESTRA HISTORIA (/nuestra-historia)
  - Línea de tiempo de la marca (hitos, año de fundación, expansión).
  - Fotografía de taller/orfebres (storytelling humano).

ESMERALDAS (/esmeraldas)
  - Explicación del proceso de selección y certificación.
  - Mapa o referencia de origen (minas de Boyacá/Muzo, sin afirmar
    datos no verificados por el cliente).

CONTACTO (/contacto)
  - Formulario (nombre, email, teléfono, mensaje).
  - Mapa embebido del showroom (si aplica).
  - Enlace directo a WhatsApp Business.
```

## 7. REQUISITOS TÉCNICOS

```

  • Stack sugerido: Next.js + React + Tailwind CSS (SSR/SSG para SEO)
  • Mobile-first, totalmente responsive: 375 / 768 / 1024 / 1440

## 8. E-COMMERCE Y FLUJO DE COMPRA

```
CATÁLOGO → FICHA DE PRODUCTO → CARRITO (drawer) → CHECKOUT → CONFIRMACIÓN

Carrito lateral (drawer):
  - Lista de productos con imagen, nombre, variante, cantidad, precio
  - Edición de cantidad in-line, eliminar producto
  - Subtotal + nota de envío ("Envío calculado en el checkout")
  - CTA "IR A PAGAR"

Checkout simplificado (idealmente 1 sola página con acordeón):
  1. Datos de envío
  2. Método de envío
  3. Método de pago — integración pasarela Colombia:
     Wompi / PayU / Mercado Pago
  4. Resumen y confirmación

Confirmación de compra:
  - Número de orden, resumen, certificado de autenticidad adjunto
  - Email de confirmación con identidad de marca (plantilla dorada/verde)

Club Ángel (newsletter con beneficios VIP):
  - Doble opt-in por email
  - Segmentación básica (cliente nuevo vs. recurrente)
```

## 9. SEO Y PERFORMANCE

```
• Meta tags optimizados: "joyas de esmeraldas Colombia", "esmeraldas
  certificadas", "joyería de lujo Medellín/Colombia", "anillos de oro
  con esmeralda colombiana"
• Schema.org: Product, Organization, BreadcrumbList, Review
• Sitemap.xml y robots.txt configurados
• Open Graph + Twitter Cards para cada producto (imagen, precio, título)
• Core Web Vitals objetivo:
    LCP < 2.5s · CLS < 0.1 · INP < 200ms
• Optimización de fuentes: `font-display: swap`, precarga de fuentes
  críticas (Cormorant Garamond / Montserrat)
```

## 10. ACCESIBILIDAD

```
• Contraste mínimo AA en todo texto (ver reglas en 2.1)
• Navegación completa por teclado (focus visible en dorado, sin outline
  eliminado)
• Alt text descriptivo en todas las imágenes de producto (material,
  tipo de joya, no solo "imagen1.jpg")
• Roles ARIA en drawer de carrito, modal de zoom y menú mobile
• Formularios con labels asociados (no solo placeholder)
• Respeto a `prefers-reduced-motion` para desactivar animaciones no
  esenciales
```

## 11. TONO Y GUÍA DE COPY

```
- Voz en primera persona de marca, cálida pero aspiracional.
- Evitar tecnicismos; usar palabras como "brillo", "alma", "legado",
  "esmeralda colombiana", "hecho a mano", "propósito".
- CTA siempre en mayúsculas cortas: "DESCUBRIR", "EXPLORAR",
  "AGENDAR ASESORÍA", "UNIRME".
- Frases cortas en encabezados (3-5 palabras), párrafos de cuerpo
  breves (máx. 3 líneas por bloque).
- Nunca usar superlativos vacíos ("el mejor", "único en el mundo") sin
  respaldo — preferir storytelling concreto (origen, proceso, materiales).
```
